# TEFAST — макет інтернет-магазину запчастин для Tesla

Статичний фронтенд-прототип (HTML, CSS, JS без збірки). Усі ціни, артикули, відгуки й залишки — **приклади**.

## Сторінки
- `index.html` — головна: hero-слайдер, швидкий підбір, моделі, категорії, хіти, переваги, відгуки, B2B, блог, FAQ, контакти
- `model.html?m=Model 3` — дерево розділів і підкатегорій моделі
- `catalog.html` — каталог з фільтрами та сортуванням
- `product.html?id=…` — картка товару
- `cart.html` — кошик та оформлення

## Запуск
```bash
python3 -m http.server 8765
```
Відкрийте http://localhost:8765/index.html. Запускати треба з папки проєкту.

## Структура
- `assets/style.css` — зібрані стилі (не правте вручну)
- `assets/data.js`, `assets/tree.js` — товари та дерево розділів
- `assets/app.js` — кошик, вкладки, рух
- `partials/` — шапка, футер, джерела стилів і сторінок
- `build.py` — збирає `assets/style.css`, `catalog.html`, `product.html`, `cart.html`, `model.html` із `partials/`
- `DESIGN.md` — дизайн-система бренду

Після змін у `partials/` запускайте `python3 build.py`.

## Примітки
- Фото моделей (`img/`) надані замовником; решта фото підтягуються з Wikimedia Commons як заглушки (CC BY-SA).
- Дерево розділів походить із таблиці замовника та однакове для Model 3, Model Y і Model S.

## B2B-кабінет для СТО (`b2b/`)
Демо без сервера: дані зберігаються в браузері (localStorage).

- `b2b/login.html` — вхід і реєстрація СТО (статуси: новий / верифікований / призупинений)
- `b2b/index.html` — головна кабінету: умови, ліміт, найближчий платіж
- `b2b/catalog.html` — каталог за деревом розділів, ціни СТО, доступність
- `b2b/quick.html` — швидке замовлення за артикулами (список або CSV/TXT)
- `b2b/cart.html` — кошик: мінімальна сума, відстрочка, кредитний ліміт
- `b2b/orders.html` — замовлення, рахунок і накладна (PDF через друк)
- `b2b/profile.html` — дані СТО й умови співпраці
- `b2b/admin.html` — панель менеджера (демо): статуси, ціни, ліміти, верифікація

Демо-акаунти (пароль `demo1234`): `sto@demo.example` (верифікований), `new@demo.example` (новий), `stop@demo.example` (призупинений).

## Адмін-панель (`admin/`)
Єдина панель для сайту й B2B. Демо без сервера: дані в localStorage (ключ `tefast-admin-db`), правки одразу видно на вітрині та в B2B у тому самому браузері.

Вхід: `admin/index.html`, пароль `admin123`, швидкий вхід під ролями (Власник, Менеджер, Контент-менеджер, Бухгалтер, Склад).

- Дашборд і аналітика: виручка, замовлення, середній чек, канали, топ товарів і СТО, промокоди, експорт CSV
- Замовлення (сайт + B2B): фільтри, статуси, історія, примітки; документи: рахунок, накладна, товарний чек, лист комплектації, акт повернення, договір для СТО (`admin/doc.html`, PDF через друк)
- Товари: пошук, фільтри, редактор, інлайн-ціна й залишок, масові дії, власні товари; категорії: порядок, видимість, нові підкатегорії
- Промокоди й акції: коди з лімітами та датами; акції на розділ, модель чи тип, що змінюють ціни на сайті
- Контент: банери головної, статті блогу, відгуки з модерацією, FAQ
- B2B: СТО, верифікація, умови, ліміти, умови за замовчуванням, цінові правила за розділами
- Доступи: користувачі, матриця ролей (немає / перегляд / редагування), журнал дій
- Налаштування: контакти, доставка, реквізити для документів, резервна копія, скидання демо-даних

`assets/live.js` накладає правки з адмінки на вітрину й B2B; `assets/defaults.js` генерується `gen_defaults.py` з `index.html`.
