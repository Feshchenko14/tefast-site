# TEFAST — макет інтернет-магазину запчастин для Tesla

Статичний фронтенд-прототип (HTML, CSS, JS без збірки). Усі ціни, артикули, відгуки й залишки — **приклади**.

## Сторінки
- `index.html` — головна: hero-слайдер, швидкий підбір, моделі, категорії, хіти, переваги, відгуки, B2B, блог, FAQ, контакти
- `model.html?m=Model 3` — дерево розділів і підкатегорій моделі
- `catalog.html` — каталог з фільтрами та сортуванням
- `product.html?id=…` — картка товару
- `cart.html` — кошик та оформлення

## Запуск
```bash
python3 -m http.server 8765
```
Відкрийте http://localhost:8765/index.html. Запускати треба з папки проєкту.

## Структура
- `assets/style.css` — зібрані стилі (не правте вручну)
- `assets/data.js`, `assets/tree.js` — товари та дерево розділів
- `assets/app.js` — кошик, вкладки, рух
- `partials/` — шапка, футер, джерела стилів і сторінок
- `build.py` — збирає `assets/style.css`, `catalog.html`, `product.html`, `cart.html`, `model.html` із `partials/`
- `DESIGN.md` — дизайн-система бренду

Після змін у `partials/` запускайте `python3 build.py`.

## Примітки
- Фото моделей (`img/`) надані замовником; решта фото підтягуються з Wikimedia Commons як заглушки (CC BY-SA).
- Дерево розділів походить із таблиці замовника та однакове для Model 3, Model Y і Model S.
